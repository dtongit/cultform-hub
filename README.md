# CULTFORM — AI-Driven 3D Production & Micro-Factories Hub

CULTFORM is a digital contract manufacturing and 3D printing platform from CAD to series in 4 days with zero tooling costs. Operating micro-factories in Turkey and Russia.

## Live Website

[https://dtongit.github.io/cultform-hub/](https://dtongit.github.io/cultform-hub/)

## Repository Structure

- `index.html` — Main landing page & interactive platform hub
- `styles.css` — Modern dark glassmorphic design system
- `app.js` — Client-side interaction & internationalization (EN/RU) logic
- `assets/` — High-resolution product showcase and facility media
